Samiti Android mobile UI update
================================
Changes:
- Polished sidebar rows with rounded icon badges and high-contrast labels.
- Theme toggle in sidebar with ON/OFF indicator.
- Admin/SuperAdmin notification bell in top app bar.
- Improved dark-mode contrast for dashboard card titles, descriptions, and paragraphs.
- Existing network UI and Firebase notification code retained.

Apply:
1. Back up your current android folder.
2. Merge the android folder from this archive into your project.
3. Keep your own android/app/google-services.json (not included here).
4. Open the android project in Android Studio, sync Gradle, then build/run.

Note: This archive is source-only; a full Gradle build and physical-device notification test are still required.
